A Ballsdex package that adds `/polos give`, an admin command that gives a player packs of 5 random balls.


Add the package by putting this in your config/extra.toml
```
[[ballsdex.packages]]
location = "git+https://github.com/kaboomtsarbobm/joshy-james.git@1.0.1"
path = "can_i_ever_afford_a_house_no"
enabled = true
```
